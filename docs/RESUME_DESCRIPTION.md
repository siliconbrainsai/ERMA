# Resume Description: Enterprise Resource Management Analytics (ERMA) Dashboard

### Project Title
**Enterprise Resource Management Analytics (ERMA) Intelligence Platform**

### Role: Lead Full Stack & BI Architect
- Architected and delivered a production-grade **Enterprise Resource Management Analytics (ERMA)** Single Page Application using **ReactJS**, **Vite**, **Recharts**, and modern corporate design aesthetics.
- Engineered 12 dynamic analytical modules covering Executive KPIs, Resource Allocation, Technical Competencies, Bench Ageing ($k drag cost), Global Mobility/Visas, Manager Span of Control, and Attrition Flight Risk.
- Built a multi-dimensional client-side data engine enabling real-time drilldown filtering across 100+ dimensions (IBU, Country, Band, Pricing Model, Tech Stack, and Customer).
- Integrated Phase 9 AI Predictive Analytics featuring 6-month utilization confidence forecasting, skill demand-supply gap matrices, and machine learning flight risk heuristic scoring.
- Implemented file ingest capabilities supporting raw Excel (.xlsx) / CSV file parsing with automatic schema normalization and one-click filtered reporting exports.
